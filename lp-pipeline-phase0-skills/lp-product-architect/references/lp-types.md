# Landing Page Types — Taxonomy & Adaptations

## How to Use

Determine the LP type FIRST. It changes everything downstream:
which questions to ask, what data to collect, CTA patterns, and success metrics.

Ask: "What's the ONE action you want someone to take on this page?"
Then match to the type below.

---

## Type 1: Service Sale (Booking/Consultation)

**Objective:** Get the prospect to schedule a call, meeting, or consultation.
**Common for:** Agencies, consultancies, freelancers, B2B services.

| Field | Details |
|-------|---------|
| **Data to collect** | Name, email, WhatsApp, company name, company size (optional) |
| **CTA patterns** | "Book Your Free [X] Analysis", "Schedule a [X]-Minute Strategy Call" |
| **Success metric** | Bookings per month, show-up rate |
| **Conversion target** | 5-12% visitor-to-booking |
| **Key questions** | What happens on the call? How fast do you follow up? What's your close rate? |
| **Offer focus** | Value of the call itself (free audit, free analysis, custom report) |
| **Guarantee focus** | "Keep the analysis even if you don't hire us" |

---

## Type 2: Direct Product Sale

**Objective:** Get immediate purchase (physical product, digital product, SaaS subscription).
**Common for:** E-commerce, infoproducts, SaaS, digital tools.

| Field | Details |
|-------|---------|
| **Data to collect** | Full checkout (name, email, payment info) |
| **CTA patterns** | "Buy Now", "Start Your Free Trial", "Get Instant Access" |
| **Success metric** | Sales per month, revenue, average order value |
| **Conversion target** | 2-5% for cold traffic, 8-15% for warm |
| **Key questions** | Price point? Payment options? Upsells? Refund policy? |
| **Offer focus** | Value stack: core product + bonuses + guarantee |
| **Guarantee focus** | 7/15/30-day money-back, results-based guarantee |

---

## Type 3: Lead Capture (Lead Magnet)

**Objective:** Capture email/WhatsApp in exchange for free value (ebook, checklist, template).
**Common for:** Content creators, coaches, SaaS (top-of-funnel), agencies.

| Field | Details |
|-------|---------|
| **Data to collect** | Name + email (minimum), WhatsApp (optional) |
| **CTA patterns** | "Download Free [X]", "Get Your [X] Now", "Access the [X]" |
| **Success metric** | Leads per month, email opt-in rate |
| **Conversion target** | 20-40% for targeted traffic |
| **Key questions** | What's the lead magnet? What's the nurture sequence after? |
| **Offer focus** | Perceived value of the free resource |
| **Guarantee focus** | "Free, no credit card required" |

---

## Type 4: Event Registration (Webinar/Workshop)

**Objective:** Get registrations for a live or recorded event.
**Common for:** Coaches, educators, SaaS launches, agencies.

| Field | Details |
|-------|---------|
| **Data to collect** | Name, email, WhatsApp (for reminders) |
| **CTA patterns** | "Reserve My Spot", "Register Free", "Save My Seat" |
| **Success metric** | Registrations, show-up rate, post-event conversion |
| **Conversion target** | 15-30% opt-in, 30-50% show-up |
| **Key questions** | When is it? What's the pitch at the end? What tool for the event? |
| **Offer focus** | What they'll LEARN + who's teaching + exclusivity |
| **Guarantee focus** | "Free + replay available" or "Limited spots (real capacity)" |

---

## Type 5: Waitlist / Pre-launch

**Objective:** Build anticipation and capture interest before launch.
**Common for:** SaaS, apps, new services, limited-edition products.

| Field | Details |
|-------|---------|
| **Data to collect** | Email only (minimum friction) |
| **CTA patterns** | "Join the Waitlist", "Get Early Access", "Be the First to Know" |
| **Success metric** | Waitlist size, conversion on launch day |
| **Conversion target** | 25-50% (low friction) |
| **Key questions** | When is launch? What's the early-bird benefit? |
| **Offer focus** | Exclusivity + early-bird pricing or features |
| **Guarantee focus** | N/A — low commitment |

---

## Type 6: Community Access

**Objective:** Get members into a free or paid community (Skool, Discord, WhatsApp group).
**Common for:** Content creators, coaches, niche communities.

| Field | Details |
|-------|---------|
| **Data to collect** | Name, email (or just community platform login) |
| **CTA patterns** | "Join the Community", "Enter Free", "Start Networking" |
| **Success metric** | New members per month, engagement rate |
| **Conversion target** | 15-30% |
| **Key questions** | What platform? Free or paid? What's inside? Who else is there? |
| **Offer focus** | Community value: who's inside, what they get, exclusivity |
| **Guarantee focus** | "Free to join" or "Cancel anytime" |

---

## Type 7: Portfolio / Authority

**Objective:** Build credibility and establish expertise (no direct conversion required).
**Common for:** Personal brands, agencies, consultants, freelancers.

| Field | Details |
|-------|---------|
| **Data to collect** | Optional (email for updates) |
| **CTA patterns** | "See Our Work", "Explore Projects", "Get in Touch" |
| **Success metric** | Time on page, project views, inbound inquiries |
| **Conversion target** | N/A (brand building) |
| **Key questions** | What work to showcase? What impression to leave? |
| **Offer focus** | Quality of work, client results, range of capabilities |
| **Guarantee focus** | N/A |

---

## Type Selection Guide

If the user isn't sure, ask:

```
"When someone visits this page, what's the ONE thing you want them to do?"

A) Schedule a call with you → Type 1 (Service Sale)
B) Buy something right now → Type 2 (Direct Sale)
C) Give you their email for something free → Type 3 (Lead Capture)
D) Register for an event → Type 4 (Event)
E) Join a waitlist → Type 5 (Waitlist)
F) Join a community → Type 6 (Community)
G) Just see your work → Type 7 (Portfolio)
```

**Mixed objectives:** If the user wants multiple actions, identify the PRIMARY one.
The LP should have ONE main CTA. Secondary objectives go in the footer or as exit-intent.
