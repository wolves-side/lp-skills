# Section Spec Patterns

Common layout patterns for each section type. Choose based on content available
and LP type. These are structural patterns — visual design comes in Phase 2.

---

## Hero Patterns

### Pattern A: Split Hero (Text + Visual)
```
┌──────────────────────────────────────────────┐
│  [NAV: Logo ---- Links ---- CTA button]      │
├──────────────────────┬───────────────────────┤
│                      │                       │
│  H1: Headline        │   [Visual element]    │
│  H2: Subheadline     │   Dashboard mockup    │
│                      │   Product screenshot  │
│  [CTA Button]        │   Video embed         │
│  microcopy           │   Illustration        │
│                      │                       │
│  Trust: logos/metric  │                       │
│                      │                       │
└──────────────────────┴───────────────────────┘
```
**Best for:** SaaS, tools with visual UI, agencies with portfolio.
**Visual split:** 55% text / 45% visual.

### Pattern B: Centered Hero (Text-Only)
```
┌──────────────────────────────────────────────┐
│  [NAV: Logo ---- Links ---- CTA button]      │
├──────────────────────────────────────────────┤
│                                              │
│              H1: Headline                    │
│           H2: Subheadline                    │
│                                              │
│             [CTA Button]                     │
│              microcopy                       │
│                                              │
│     Trust: logo1  logo2  logo3  logo4        │
│                                              │
└──────────────────────────────────────────────┘
```
**Best for:** Service sales, personal brands, B2B. Clean, focused.
**Works when:** No strong visual to show. Let copy do the work.

### Pattern C: Hero with Featured Result
```
┌──────────────────────────────────────────────┐
│  [NAV]                                       │
├──────────────────────────────────────────────┤
│                                              │
│  H1: Headline                                │
│  H2: Subheadline                             │
│  [CTA Button]                                │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │  FEATURED CASE: "12,000+ invoices      │  │
│  │  processed/month for [Client]"         │  │
│  │  [mini metrics: time saved, accuracy]  │  │
│  └────────────────────────────────────────┘  │
│                                              │
└──────────────────────────────────────────────┘
```
**Best for:** When you have one STRONG case study. Maximum credibility.

## Problem Section Patterns

### Pattern A: Narrative Block
```
┌──────────────────────────────────────────────┐
│  H2: "Sound familiar?"                       │
│                                              │
│  [2-3 paragraphs of problem description      │
│   in customer language]                      │
│                                              │
└──────────────────────────────────────────────┘
```
**Best for:** When the problem is emotional/complex. Long-form empathy.

### Pattern B: Pain Point Cards
```
┌──────────────────────────────────────────────┐
│  H2: "The problems keeping you up at night"  │
│                                              │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │ ❌ Pain 1 │ │ ❌ Pain 2 │ │ ❌ Pain 3 │    │
│  │ Detail   │ │ Detail   │ │ Detail   │    │
│  └──────────┘ └──────────┘ └──────────┘    │
│                                              │
└──────────────────────────────────────────────┘
```
**Best for:** When there are 3-4 distinct pain points. Scannable.

```

│                                              │
│  ┌──────────────────────────────────────┐    │
│  │  Case 1: Title  │  Case 2: Title    │    │
│  │  Challenge       │  Challenge        │    │

│                                              │
│                 [CTA Button]                 │
```

**Best for:** When you have real numbers AND real cases. Maximum trust.

```
┌──────────────────────────────────────────────┐

│                                              │

```
**Best for:** When you have recognizable logos. Quick visual trust.

## Feature Section Patterns

### Pattern A: Alternating Rows
```
┌──────────────────────────────────────────────┐
│  ┌─────────────────┬────────────────────┐    │
│  │  Feature 1 text │  [Visual/icon]     │    │
│  ├────────────────-┼────────────────────┤    │
│  │  [Visual/icon]  │  Feature 2 text    │    │
│  ├─────────────────┼────────────────────┤    │
│  │  Feature 3 text │  [Visual/icon]     │    │
│  └─────────────────┴────────────────────┘    │
└──────────────────────────────────────────────┘
```
**Best for:** 3-4 features with visual elements. Good reading rhythm.

### Pattern B: Card Grid
```
┌──────────────────────────────────────────────┐
│  H2: "What you get"                          │
│                                              │
│  ┌──────┐ ┌──────┐ ┌──────┐                │
│  │Icon  │ │Icon  │ │Icon  │                │
│  │Title │ │Title │ │Title │                │
│  │Desc  │ │Desc  │ │Desc  │                │
│  └──────┘ └──────┘ └──────┘                │
│  ┌──────┐ ┌──────┐ ┌──────┐                │
│  │Icon  │ │Icon  │ │Icon  │                │
│  │Title │ │Title │ │Title │                │
│  │Desc  │ │Desc  │ │Desc  │                │
│  └──────┘ └──────┘ └──────┘                │
└──────────────────────────────────────────────┘
```
**Best for:** 6 features, all equal importance. Scannable grid.

## Offer Block Patterns

### Pattern A: Centered Offer Card
```
┌──────────────────────────────────────────────┐
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │  H2: "Ready to [transformation]?"      │  │
│  │                                        │  │
│  │  ✅ What you get item 1                │  │
│  │  ✅ What you get item 2                │  │
│  │  ✅ What you get item 3                │  │
│  │                                        │  │
│  │  PRICE: [amount]                       │  │
│  │  (anchoring comparison)                │  │
│  │                                        │  │
│  │  ⬛ [CTA BUTTON — largest on page]     │  │
│  │  microcopy                             │  │
│  │                                        │  │
│  │  🔒 Guarantee statement                │  │
│  └────────────────────────────────────────┘  │
│                                              │
└──────────────────────────────────────────────┘
```
**Best for:** Direct sales, courses, SaaS. Clear decision point.

### Pattern B: Split Offer (for service sales without visible price)
```
┌──────────────────────────────────────────────┐
│  ┌──────────────────┬─────────────────────┐  │
│  │  H2: Value prop  │  FORM:              │  │
│  │                  │  [Name]             │  │
│  │  What you get:   │  [Email]            │  │
│  │  ✅ Item 1       │  [WhatsApp]         │  │
│  │  ✅ Item 2       │  [Company]          │  │
│  │  ✅ Item 3       │                     │  │
│  │                  │  [CTA BUTTON]       │  │
│  │  Guarantee       │  microcopy          │  │
│  └──────────────────┴─────────────────────┘  │
└──────────────────────────────────────────────┘
```
**Best for:** Service bookings, consultations. Form is the CTA.

## Comparison Patterns

```

│  H2: "Why [Company] vs the alternative"      │
│                                              │
│  Feature        │ Us      │ Enterprise │ DIY │
│  ──────────────-┼─────────┼────────────┼─────│

│  Time to value  │ 2 weeks │ 6 months   │ ??? │
└──────────────────────────────────────────────┘
```

### Pattern B: Two-Column (Us vs Them)
```
┌──────────────────────────────────────────────┐
│  ┌─────────────────┬─────────────────────┐   │
│  │  ❌ WITHOUT US   │  ✅ WITH US         │   │

│  │  Pain point 3   │  Benefit 3          │   │
│  └─────────────────┴─────────────────────┘   │
└──────────────────────────────────────────────┘
```

## FAQ Pattern

Always use accordion (expandable) on desktop and mobile:
```
┌──────────────────────────────────────────────┐
│  H2: "Frequently Asked Questions"            │
│                                              │
│  ▸ Question 1?                               │
│  ▸ Question 2?                               │
│  ▾ Question 3? (expanded)                    │
│    [Answer text visible when expanded]       │
│  ▸ Question 4?                               │
│  ▸ Question 5?                               │
└──────────────────────────────────────────────┘
```
First question expanded by default to signal interactivity.
