# Competitor Extraction Checklist

## Per-Competitor Data Points

For each competitor LP, extract the following. Use `web_fetch` on their URL.
If the page is JavaScript-heavy and content doesn't load, note "JS-rendered, partial data" and
capture what's available from the raw HTML.

---

### Identity

| Field | What to Capture |
|-------|----------------|
| Company name | Exact name as displayed |
| URL | Full landing page URL |
| Tagline / Slogan | If visible in header or hero |
| Industry position | Direct competitor / Indirect / Aspirational |

### Hero Section

| Field | What to Capture |
|-------|----------------|
| Headline | Exact text |
| Subheadline | Exact text (if exists) |
| CTA button text | Exact text |
| CTA button color | Hex or description |
| Hero media | Image / Video / Animation / Screenshot / None |
| Above-the-fold trust | Any social proof visible before scroll |

### Value Proposition

| Field | What to Capture |
|-------|----------------|
| Main promise | What do they promise in 1 sentence? |
| Key benefits listed | List of benefits/features they highlight |
| Differentiator claimed | How they say they're different |
| Specificity level | Vague ("best in class") vs Specific ("47% faster in 3 weeks") |

### Social Proof

| Field | What to Capture |
|-------|----------------|
| Testimonials | Count, format (text/video/screenshot), named or anonymous |
| Client logos | Count, recognizable brands? |
| Case studies | Present? Detailed or summary? |
| Numbers displayed | Revenue, clients, years, team size, etc. |
| Certifications/Awards | Any badges, partnerships, certifications |
| Media mentions | Press logos or article references |

### Pricing & Offer

| Field | What to Capture |
|-------|----------------|
| Pricing visible? | Yes / No / "Contact us" |
| Price range | If visible |
| Pricing model | One-time / Monthly / Tiered / Custom |
| Guarantee | Type and exact text |
| Free offer | Lead magnet, trial, consultation? |
| Urgency/Scarcity | Any scarcity elements? Real or fake? |

### Page Structure

| Field | What to Capture |
|-------|----------------|
| Section order | List sections top to bottom (e.g., Hero → Features → Testimonials → Pricing → CTA) |
| Page length | Short (1 scroll) / Medium (3-4 scrolls) / Long (5+ scrolls) |
| Number of CTAs | Count + positions on page |
| FAQ present? | Yes / No |
| Contact form fields | What data they collect |

### Visual & Technical

| Field | What to Capture |
|-------|----------------|
| Primary colors | Hex codes or descriptions |
| Font style | Serif / Sans-serif / Display (approximate) |
| Imagery style | Stock photos / Custom / Illustrations / Screenshots / Abstract |
| Design aesthetic | Minimalist / Corporate / Playful / Dark / Glassmorphism / etc. |
| Animations | Heavy / Light / None |
| Mobile-ready? | If checkable |

### Copy & Tone

| Field | What to Capture |
|-------|----------------|
| Tone | Professional / Casual / Technical / Bold / Inspirational |
| Point of view | "We" / "You" / "I" focused |
| Power words used | List 3-5 notable word choices |
| Jargon level | High (industry insiders) / Medium / Low (accessible) |
| Emotional angle | Fear / Aspiration / Logic / Urgency / Trust |

---

## Quick-Score Card

After extraction, rate each competitor (1-5) on:

| Dimension | 1 (Weak) | 5 (Strong) |
|-----------|----------|------------|
| **Copy clarity** | Vague, generic | Specific, compelling |
| **Social proof** | None or fake | Real, named, detailed |
| **Visual design** | Dated, cluttered | Modern, clean, distinctive |
| **Offer strength** | No guarantee, hidden price | Clear guarantee, transparent |
| **Differentiation** | Same as everyone | Clearly unique positioning |
| **Overall threat** | Easy to beat | Formidable competitor |

This scorecard helps prioritize which competitors to study deeper and which
weaknesses to exploit most aggressively.
