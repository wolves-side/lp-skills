# Section Build Patterns

> **This file has been superseded by `component-patterns.md`.**
>
> All section patterns are now React/TSX components.
> See `references/component-patterns.md` for complete patterns including:
>
> - Hero (Split + Centered layouts)
> - Problem (Narrative + Pain Cards)
> - Social Proof (Metrics + Cases)
> - Features (Card Grid)
> - Offer Block
> - FAQ (Shadcn Accordion)
> - Testimonials (Cards)
> - Final CTA
> - Footer
>
> Each component uses:
> - TypeScript interfaces for props
> - Framer Motion for animations (via `ScrollReveal`, `StaggerChildren`)
> - Shadcn UI for base components
> - Lucide React for icons
> - Tailwind CSS for styling
